# A/L Chemistry Master Hub (Android & Cross-Platform)

An interactive, modern application built with **Jetpack Compose**, **Kotlin**, and **Material 3** for Sri Lankan G.C.E. Advanced Level (A/L) Chemistry students.

## Features

- **Unit-by-Unit Syllabus Breakdown**: 9 comprehensive core units:
  - Inorganic Chemistry (12 Lessons)
  - Chemical Kinetics (12 Lessons)
  - Organic Chemistry (39 Lessons)
  - Equilibrium — Kp & Kc (10 Lessons)
  - Solubility Product — Ksp (5 Lessons)
  - Buffer & Region Equilibrium (8 Lessons)
  - pH & Aqueous Solutions (10 Lessons)
  - Electrochemistry (7 Lessons)
  - Industrial Chemistry (16 Lessons)
- **119+ Curated Video Lectures**: Direct one-tap playback for YouTube and Rumble lectures.
- **Study Material Archives**: Instant access to Telegram Channel, Google Drive PDF tutes archive, and Charitha Dissanayake Masterclass recordings.
- **Interactive Progress Tracker**: Track study completion with animated progress bars, per-unit breakdown, and persistent SharedPreferences checklist.
- **Global Search & Filter**: Real-time filtering across topics, lesson names, and Sinhala subtitles.
- **Adaptive Design**: Responsive layout supporting compact handheld devices and expanded tablet screens with Material 3 Navigation.
- **Custom Adaptive Icon & Artwork**: Designed with Material You guidelines, custom adaptive foreground/background, and generated visual hero banners.

## Android Architecture

- **Language**: Kotlin 2.0+
- **UI Toolkit**: Jetpack Compose with Material Design 3 (M3)
- **Architecture**: MVVM with `ChemistryViewModel` and Kotlin `StateFlow`
- **Application ID**: `com.aistudio.alchemistry.kxmpzq`
- **Persistence**: SharedPreferences / Android State management
